    📖 Jak psát SQL

    SQL je jazyk, kterým se ptáme databáze. Databáze jsou tabulky: sloupce říkají, co o věci víme, a každý řádek je jedna věc (třeba člověk).

    SELECT … FROM …

    Co chceš vidět a odkud. Hvězdička = všechny sloupce.

    SELECT jmeno, role FROM posadka

    WHERE

    Vybere jen řádky, které splní podmínku. Text patří do apostrofů, čísla ne. Podmínky spojíš AND (obě) nebo OR (aspoň jedna).

    SELECT * FROM posadka
WHERE oddeleni = 'energetika' AND vek > 30

    ORDER BY, LIMIT

    Seřadí výsledek (DESC = od největšího) a omezí počet řádků.

    SELECT jmeno, vek FROM posadka
ORDER BY vek DESC LIMIT 3

    LIKE, BETWEEN

    LIKE hledá text podle vzoru (% je libovolný text), BETWEEN vybere hodnoty v rozsahu.

    WHERE jmeno LIKE 'B%'
WHERE vek BETWEEN 20 AND 40

    COUNT, SUM, AVG, MIN, MAX, DISTINCT

    Počítání místo vypisování. DISTINCT vypíše každou hodnotu jen jednou.

    SELECT COUNT(*) FROM posadka
SELECT AVG(vek) FROM posadka
SELECT DISTINCT oddeleni FROM posadka

    GROUP BY, HAVING

    GROUP BY udělá skupiny, HAVING vybere z hotových skupin.

    SELECT oddeleni, COUNT(*) FROM posadka
GROUP BY oddeleni HAVING COUNT(*) > 2

    JOIN

    Spojí dvě tabulky podle společné hodnoty. Před název sloupce napiš tabulku a tečku.

    SELECT posadka.jmeno, vstupy.cas
FROM vstupy
JOIN posadka ON vstupy.osoba_id = posadka.id
