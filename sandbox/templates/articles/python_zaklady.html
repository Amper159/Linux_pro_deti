Co je Python a proč začít právě jím

Python je programovací jazyk, ve kterém se dají psát hry, weby, analýzy dat i skripty pro automatizaci. Používá ho spousta firem a škol. Pro začátek se hodí, protože se dá číst skoro jako věty a nutí tě psát přehledně: struktura programu se pozná podle odsazení řádků.

Kde Python spustit

  • Online v prohlížeči. V Python Labu na tomhle webu napíšeš kód a hned ho spustíš. Nic neinstaluješ.
  • Na svém počítači. Ve Windows a macOS stáhni Python 3 ze stránky python.org/downloads. Při instalaci ve Windows zaškrtni „Add python.exe to PATH“, jinak ho terminál nenajde. Na většině distribucí Linuxu je Python už předinstalovaný, ověříš to příkazem python3 --version.
  • Editor. Pro psaní programů se hodí Thonny (jednoduchý, určený začátečníkům) nebo Visual Studio Code s rozšířením pro Python.

Program uložený v souboru muj_program.py spustíš v terminálu příkazem python muj_program.py (v Linuxu a macOS python3 muj_program.py).

Proměnné a typy hodnot

Proměnná je jméno, pod kterým si Python zapamatuje hodnotu, aby ji šlo použít znovu. Znaménko = tady neznamená „rovná se“ jako v matematice, ale „ulož hodnotu vpravo do proměnné vlevo“.

{{ run('promenne') }}

Hodnoty mají různé typy. Text je str, celé číslo int, desetinné číslo float a pravda či nepravda bool. Typ zjistíš funkcí type():

{{ run('typy') }}

Text v uvozovkách a číslo bez nich jsou pro Python různé věci. "12" je text, se kterým se nedá počítat, 12 je číslo.

Počítání a spojování textu

Python počítá jako kalkulačka. Kromě základních operací umí dělení beze zbytku (//), zbytek po dělení (%) a mocninu (**).

{{ run('pocitani') }}

Text s proměnnými se nejpohodlněji spojuje pomocí f-řetězce: před uvozovky se napíše f a proměnné se vloží do složených závorek.

{{ run('fstring') }}

Program se může uživatele i ptát pomocí funkce input():

{{ run('input') }}

Podmínky: if, elif, else

Podmínka nechá program rozhodnout se podle situace. if zkusí první podmínku, elif („else if“) další, pokud ta první neplatila, a else se provede ve všech ostatních případech. Části elif a else jsou nepovinné.

{{ run('podminky') }}

Podmínky se dají kombinovat pomocí and (musí platit obě), or (stačí jedna) a not (obrácení). Porovnávat lze pomocí == (rovná se), != (nerovná se), <, >, <= a >=. Pozor, na porovnání se používají dvě rovnítka, jedno by hodnotu ukládalo.

{{ run('logika') }}

Odsazení: pravidlo, které Python odlišuje

Ve většině jazyků se bloky kódu ohraničují závorkami. Python místo toho pozná, co patří „dovnitř“ podmínky, smyčky nebo funkce, podle odsazení řádku. Doporučuje se 4 mezery. Řádek, po kterém následuje odsazený blok, končí dvojtečkou.

Pravidlo je přísné: kód uvnitř bloku musí být odsazený stejně a nesmíš míchat mezery s tabulátory. Většina editorů to hlídá za tebe, klávesa Tab vloží odsazení.

Smyčky: for a while

Smyčka opakuje kus kódu, abys ho nemusel psát pořád dokola. for použij, když víš dopředu, přes co procházíš. Funkce range(1, 4) vytvoří čísla od 1 do 3, koncové číslo se nezahrnuje.

{{ run('for') }}

while se opakuje, dokud platí podmínka, a hodí se, když předem nevíš, kolikrát. Nezapomeň v ní něco měnit, jinak vznikne nekonečná smyčka.

{{ run('while') }}

Seznamy a slovníky

Seznam (list) drží více hodnot ve správném pořadí. Prvky se číslují od nuly. Přidat prvek umí append(), délku zjistí len().

Slovník (dict) páruje klíč s hodnotou, třeba jméno hrdiny s počtem životů. K hodnotě se dostaneš přes klíč v hranatých závorkách.

{{ run('slovnik') }}

Funkce

Funkce je vlastní příkaz, který si napíšeš a pak podle jména voláš, kdykoliv ho potřebuješ. Definuje se klíčovým slovem def, parametry jsou v závorce a odsazené tělo funkce obsahuje, co se má stát.

{{ run('funkce') }}

Časté nedorozumění je rozdíl mezi print() a return. print() jen vypíše hodnotu na obrazovku. return ji vrátí tomu, kdo funkci zavolal, aby se s ní dalo dál pracovat, například ji uložit do proměnné.

{{ run('return') }}

Časté chyby začátečníků

Chyby jsou úplně normální a Python ti k nim napíše, co je špatně. Nejčastější z nich vypadají takhle. Přesné znění hlášek se mezi verzemi Pythonu mírně liší.

SyntaxError: chybí dvojtečka

Za if, for, while a def musí být dvojtečka.

{{ chyba('err_syntax') }}

IndentationError: chybí odsazení

Řádek po dvojtečce musí být odsazený.

{{ chyba('err_indent') }}

NameError: překlep v názvu

Python nezná proměnnou, kterou nikdo nevytvořil. Nejčastěji je za tím překlep. Python často navíc napíše, jak by se proměnná mohla jmenovat správně.

{{ chyba('err_name') }}

TypeError: spojení textu s číslem

Text a číslo se nedají sečíst. Číslo musíš převést na text funkcí str() nebo použít f-řetězec.

{{ chyba('err_type') }}

ZeroDivisionError: dělení nulou

Nulou se dělit nedá. Před dělením hlídej, jestli dělitel není nula.

{{ chyba('err_zero') }}
