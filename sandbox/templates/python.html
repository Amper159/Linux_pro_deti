📖 Jak psát Python kód

1. Odsazení místo závorek

Jiné jazyky ohraničují blok kódu složenými závorkami { }. Python místo toho pozná, co patří "dovnitř" if, for, while nebo def, podle toho, o kolik je řádek odsazený (posunutý doprava).

2. Vždy 4 mezery, ne tabulátor

Doporučené (a v tomhle editoru automatické) odsazení jsou 4 mezery. Důležité je, aby sis v jednom bloku nemíchal mezery a tabulátory - Python by pak hlásil chybu IndentationError. V tomhle editoru klávesa Tab vloží rovnou 4 mezery, takže se tím nemusíš trápit.

3. Dvojtečka na konci řádku

Řádek, po kterém následuje odsazený blok, končí dvojtečkou : 

if cislo > 10:
    print("velke cislo")
else:
    print("male cislo")

4. Příklad se smyčkou a funkcí

def pozdrav(jmeno):
    print(f"Ahoj, {jmeno}!")

for j in ["Ema", "Tomas"]:
    pozdrav(j)

Všimni si: kód uvnitř def i for je odsazený o 4 mezery. Jakmile se odsazení vrátí zpátky doleva, blok končí.
