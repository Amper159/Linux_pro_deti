📖 Jak psát Python kód

1. Proměnná = krabička na hodnotu

Proměnná je jméno, pod kterým si Python "zapamatuje" nějakou hodnotu, abys ji mohl použít znovu, aniž bys ji musel psát pořád dokola. Zápis vek = 12 znamená "do krabičky jménem vek ulož číslo 12". Znaménko = tady neznamená "rovná se" jako v matematice, ale "přiřaď hodnotu vpravo do proměnné vlevo".

2. Text v uvozovkách, čísla bez nich

jmeno = "Ema" - uvozovky říkají Pythonu "tohle je text (řetězec), neřeš, co znamená, jen si to ulož jako je". Bez uvozovek by si Python myslel, že Ema je jméno nějaké proměnné, a spadl by s chybou, že takovou proměnnou nezná. Čísla se naopak uvozovkami neobalují - vek = 12, ne vek = "12" (to druhé by byl text vypadající jako číslo, se kterým nejde počítat).

3. Odsazení místo závorek

Jiné jazyky ohraničují blok kódu složenými závorkami { }. Python místo toho pozná, co patří "dovnitř" if, for, while nebo def, podle toho, o kolik je řádek odsazený (posunutý doprava). Autoři Pythonu to takhle schválně navrhli, aby kód, co lidi píšou, vypadal přehledně sám od sebe - nejde napsat "škaredý" kód, aniž by to bylo hned vidět.

4. Vždy 4 mezery, ne tabulátor

Doporučené (a v tomhle editoru automatické) odsazení jsou 4 mezery. Důležité je, aby sis v jednom bloku nemíchal mezery a tabulátory - Python by pak hlásil chybu IndentationError. V tomhle editoru klávesa Tab vloží rovnou 4 mezery, takže se tím nemusíš trápit.

5. Dvojtečka na konci řádku

Řádek, po kterém následuje odsazený blok, končí dvojtečkou : - je to jako "začíná tu vnořený seznam pokynů". Je to malá, ale snadno přehlédnutelná věc - hodně začátečnických chyb je jen zapomenutá dvojtečka. 

if cislo > 10:
    print("velke cislo")
else:
    print("male cislo")

6. Podmínky (if / elif / else)

Podmínka nechá program rozhodnout se podle situace - "pokud platí tohle, udělej A, jinak udělej B". if zkusí první podmínku, elif ("else if") další podmínku, pokud ta první neplatila, a else je "ve všech ostatních případech". elif a else jsou nepovinné.

7. Smyčky (for / while)

Smyčka opakuje kus kódu, abys ho nemusel opisovat pořád dokola. for použij, když víš dopředu, přes co procházíš (seznam, rozsah čísel) - "pro každou položku udělej tohle". while použij, když se má opakovat, dokud platí nějaká podmínka, a nevíš předem přesně kolikrát.

8. Funkce - print() vs. return

Funkce je "recept", který si sám napíšeš a pak podle jména zavoláš, kdykoliv ho potřebuješ, místo aby ses opisoval. Časté zmatení: print() jen vypíše něco na obrazovku - je to jen zpráva pro tebe. return naopak vrátí hodnotu zpátky tomu, kdo funkci zavolal, aby se s ní dalo dál pracovat (uložit do proměnné, počítat s ní). Funkce, co jen vypisuje, ale nic nevrací, je k ničemu, pokud potřebuješ výsledek použít dál v programu.

9. Komentáře (#)

Cokoliv za znakem # Python úplně ignoruje - je to poznámka jen pro lidi, co kód čtou (včetně tebe za měsíc, až si nebudeš pamatovat, proč jsi to tak napsal).

10. Příklad se vším dohromady

def pozdrav(jmeno):
    print(f"Ahoj, {jmeno}!")

for j in ["Ema", "Tomas"]:
    pozdrav(j)

Všimni si: kód uvnitř def i for je odsazený o 4 mezery. Jakmile se odsazení vrátí zpátky doleva, blok končí.
